cso2iso

Expands compressed .cso and .zso disc images back into plain .iso files. One small download, nothing to install.

How to run it

Unpack the archive first. Then follow the steps for your system.

  1. Unzip the download. You get a folder with cso2iso.exe inside.
  2. Drag your .cso file onto cso2iso.exe. The .iso appears next to the original.
  3. Prefer typing? Open the folder, type cmd in the address bar, press Enter, then run:
cso2iso.exe "C:\games\Wipeout Pure.cso"

The first launch may show Windows protected your PC, because the build is not code signed. Choose More info, then Run anyway.

  1. Double-click the .tar.gz to unpack it, then open Terminal.
  2. Type cd and drag the unpacked folder into the window, then press Enter.
  3. Clear the quarantine flag macOS puts on browser downloads, then convert:
xattr -dr com.apple.quarantine cso2iso
./cso2iso ~/Downloads/game.cso

Not sure whether you need the Apple Silicon or the Intel build? Apple menu → About This Mac. Anything listing an Apple M chip takes arm64.

  1. Unpack the archive and enter the folder.
  2. Make the file executable, then convert:
tar -xzf cso2iso-linux-x86_64.tar.gz
cd cso2iso-linux-x86_64
chmod +x cso2iso
./cso2iso ~/roms/game.cso

Want it available everywhere? sudo install -m 755 cso2iso /usr/local/bin/

  1. Any system with Python 3.9 or newer can run the script directly. There is nothing to install.
curl -LO https://raw.githubusercontent.com/CydVilla/cso-to-iso/main/cso2iso.py
python3 cso2iso.py game.cso

# or install it as a command
pipx install git+https://github.com/CydVilla/cso-to-iso

Using it

One image, a whole folder, or just a look inside.

cso2iso game.cso                 # writes game.iso next to it
cso2iso game.cso out/game.iso    # choose the name
cso2iso *.cso -o isos/           # convert a folder
cso2iso --info game.cso          # show what is inside, convert nothing
InputNotes
.cso / .cisoCISO v0, v1 and v2, the format almost every tool writes
.zsoZISO, the LZ4 flavour

Output is byte-for-byte identical to the ISO the image was made from. A run that is interrupted never leaves a half-written ISO behind.
